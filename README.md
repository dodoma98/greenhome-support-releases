# 그린홈시스 지원 콘솔 — 설치 파일 배포

사내 직원용 **지원 콘솔**(마케팅·CX) 데스크톱 앱의 설치 파일과 자동 업데이트 파일만
올라가는 저장소입니다. 소스 코드는 여기 없습니다.

## 설치

[Releases](../../releases/latest) 에서 `greenhome-support-<버전>-setup.exe` 를 받아 실행합니다.
설치한 뒤에는 앱이 새 버전을 알아서 받아 두고, **앱을 닫을 때** 적용합니다.

- 직원 계정으로 로그인해야 화면이 열립니다.
- 자체 서명 인증서라 처음 실행할 때 Windows 경고가 뜰 수 있습니다(관리자 콘솔과 같습니다).

## 왜 공개 저장소인가

설치된 앱이 **인증 없이** 업데이트를 받아야 하기 때문입니다. 올라가는 것은 설치 파일 ·
`latest.yml` · `.blockmap` 뿐입니다.
